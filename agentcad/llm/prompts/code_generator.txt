2. FREECADCMD 1.1.x ENTRY-POINT RULE
======================================================================

FreeCADCmd 1.1.x may load Python files with import-like semantics.

Therefore the generated script MUST NOT rely exclusively on:

    if __name__ == "__main__":

to start execution.

The final execution call MUST occur at module level.

Preferred pattern:

    try:
        generate_model()
        print("AGENTCAD_SUCCESS")
    except Exception:
        import traceback
        traceback.print_exc()
        raise

Do NOT wrap the only call to generate_model() inside:

    if __name__ == "__main__":

because the script may then load without actually executing the model generation.

7. STL EXPORT FOR VISUALIZATION
======================================================================

The STL file is for visualization and geometric inspection.

The STL visualization mesh is NOT the FEM mesh.

For ordinary export of the final Part TopoShape, prefer direct STL export:

    final_obj.Shape.exportStl(stl_path)

This is the preferred geometry-only strategy.

Do NOT use:

    Mesh.Mesh(final_obj.Shape)

or:

    Mesh.Mesh(part_solid)

because a Part.Solid / Part.TopoShape is not a valid direct constructor input
for Mesh.Mesh in this workflow.

Use MeshPart.meshFromShape() only if explicit tessellation control is truly
required.

If MeshPart.meshFromShape() is required, use explicit named parameters, e.g.:

    import MeshPart

    mesh = MeshPart.meshFromShape(
        Shape=final_obj.Shape,
        LinearDeflection=0.5,
        AngularDeflection=0.1,
        Relative=False,
    )

    mesh.write(stl_path)

Do not introduce MeshPart merely as an unnecessary fallback.

For simple geometry-only export, prefer:

    final_obj.Shape.exportStl(stl_path)

15. FEM MESH
======================================================================

The FEM mesh must follow MeshSpec exactly.

Respect:

- model_dimension: 1D / 2D / 3D
- element_family
- element_order: FIRST / SECOND
- global element size
- local refinements, if specified

For a standard 3D solid analysis, prefer Gmsh-based volume meshing.

Do not confuse:

- STL tessellation parameters
with
- FEM mesh parameters

They are different.

For example:

    Shape.exportStl(...)

is only visualization/export.

Gmsh mesh generation is the FEM discretization.

If second-order elements are requested, configure the FEM mesher accordingly.
If first-order elements are requested, do not generate second-order elements.

If global mesh size is AUTO, derive it deterministically from the geometry or
use the FreeCAD/Gmsh automatic setting, and document the choice in comments.
Do not silently change an explicit user-provided size.
